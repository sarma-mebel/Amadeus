The companion update: she reaches out, you talk like a call, and anyone can join.

## Talking to her

- **Call mode.** One tap and the conversation runs like a phone call: she
  listens when she finishes speaking, you interrupt just by talking, and a
  small HUD shows listening / thinking / speaking with an end-call button.
- **Talk gestures, restocked.** Five vetted talking-loop animations instead
  of one, so long replies stop repeating the same gesture.
- **Thinking sounds.** Run `python scripts/generate_fillers.py` once and she
  hums a short beat in her own voice while composing a longer reply, instead
  of leaving dead air. Toggle it in Settings.
- **Emotion in her voice (optional).** Record short reference clips like
  `kurisu_ref_happy.wav` next to the base voice reference and sentences
  tagged with that emotion are cloned from the matching clip. Details in
  docs/voice-expressiveness.md.

## She remembers, and follows up

- **Proactive follow-ups.** Mention an interview on Monday and Tuesday's
  greeting asks how it went. One thread at a time, each asked about exactly
  once.
- **Memory protection.** Rolling daily backups of her memory files, plus
  one-click export and import in the memory panel. One corrupted file never
  means total loss again.

## She can reach you (only if you ask)

- **Desktop notifications, done natively.** Due reminders, the morning
  brief, and her diary can reach you while the app is minimized: native
  Windows toasts on desktop, web notifications in the browser. Off by
  default, hard daily caps, and never used to pull you back in. The rules
  live in docs/companion-ethics.md.
- **Screen companion (pet mode).** Opt-in: every few minutes she glances at
  your screen and reacts with one line. Always-visible indicator, server
  cooldown, and nothing is ever stored, neither the image nor her comment.

## Anyone can join

- **Android app.** Sideload the APK, point it at your server on first
  launch, and the full experience (chat, streaming voice, the 3D avatar)
  runs on your phone.
- **Japanese UI.** The whole interface speaks Japanese (Settings → Language,
  and Japanese browsers get it by default).
- **First-run that holds your hand.** A setup wizard with live key testing
  and a voice picker, an interactive `--init-config`, and an offline-demo
  banner you cannot miss.
- **Character packs.** One folder (or zip) with a prompt, avatar, and voice
  clip; one command installs it. Kurisu is the flagship persona, not the
  limit (see docs/characters.md).
- **Hosted demo mode.** Settings locked and per-visitor rate limits, so a
  public instance is safe out of the box (docs/hosted-demo.md).

## Also

- Memory import/export API, `/api/screen_peek`, `web.demo_mode`,
  `web.rate_limit_per_minute`, the `character:` config section, and a
  `build-android` release job.
- Council mode is now marked experimental and documented as such.

## Downloads

- **Amadeus.Kurisu_0.12.0_x64-setup.exe**: Windows installer (CPU voice).
- **Amadeus-Kurisu-portable-windows.zip**: no-install portable version.
- **Amadeus-Kurisu-GPU-portable-windows.7z.001 / .002**: the GPU build with
  the Qwen3 voice clone (needs an NVIDIA GPU, 8 GB VRAM). Download both
  parts into the same folder, select them, and use 7-Zip "Extract here";
  it joins the volumes automatically.
- **Amadeus-Kurisu-android.apk**: sideload on Android and point it at your
  self-hosted server (docs/android.md).

The large voice and avatar assets ship separately as
`amadeus-runtime-assets.zip` on the `assets-v1` release.
